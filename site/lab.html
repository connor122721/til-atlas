Replication lab

Re-deriving the central result of Krishna et al. (Science 2020) — stem-like CD39⁻CD69⁻ CD8⁺ cells in the infusion product track with response — and following clones from tumor to product to blood, as in Chiffelle et al. (Immunity 2024). The pages read small JSON files exported by the scripts in analysis/; raw data stays on your cluster.

Load more datasets

Each dataset gets its own folder under analysis/datasets/ with a run.sh that downloads, prepares and exports it; the export registers itself in site/data/lab/index.json, so it appears in the dataset picker after you commit.

1
Melanoma checkpoint, ready to run. bash analysis/datasets/sadefeldman2018/run.sh (GSE120575, ~64 GB RAM). Patient and response come with the GEO files, so nothing to fill in. Same question as Krishna in a different therapy: baseline tumors, not infusion products.
2
Lausanne TIL-ACT and cervical TIL, one sample sheet each. bash analysis/datasets/chiffelle2024/run.sh and …/huang2022/run.sh download the GEO files, find every 10x sample, and write data/processed/<id>/samples.csv. Fill in patient, compartment and response from the GEO sample titles and the papers' tables, then run the script again.
3
Use the real signatures. Replace the starter marker panels in analysis/signatures/ with the CD39⁻CD69⁻ / CD39⁺CD69⁺ genes from the Krishna supplement before you call it a replication.
4
Publish. git add site/data/lab && git commit && git push. Real exports set meta.synthetic = false, and the page opens on the first real dataset.
